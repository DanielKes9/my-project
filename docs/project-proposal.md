## 1. The problem and goal

(Explain the problem you want to solve and why it matters. Describe what you
want to improve, how you will measure improvement, and which limits or
requirements must be respected. A short example can help someone outside your
field understand the problem.)

**The problem and goal in my project:**

Developing code that runs an RMG script to create a model requires knowledge of writing code. For a person who is not a software engineer, an agent that writes the code could be a huge help. Writing the code with the agent will make the development faster and, hopefully, more accurate, achieving better results, since the code involves thousands of lines, which are easier for an agent to follow. In addition, the code is very important because the model is generated from it, and it can be very valuable to the chemical research community: a model generated by a computer saves researchers time and reduces trial and error in the lab. The improvement will be measured against a target given to the agent in writing: the specific products, or the reaction family, that the model development should focus on. The goal is reached when the model that RMG generates includes them.

## 3. The agent's role

(Explain what the language-model-based agent will decide or change, and how it

**The agent in my project:**

The agent will look at the .json, .html and/or .yaml files exported in the last run and check the results of the model, meaning which reactions occur and which species RMG generated. The agent will be directed to resolve the production of specific species, or of a reaction family, that the researcher knows should be created, based on the chemical background of the reaction. I expect the language model to contribute because RMG's code is thousands of lines long, so investigating where a problem in the current model could be, and noticing what needs to be changed, added or removed, is hard. An agent would do this much faster, and could potentially resolve problems and advance the software development tremendously. Could a simple program that tries different options and picks the best result achieve the same goal? I do not believe so: RMG is made of thousands of lines of code in many files that work together, and I do not believe that a simple program could do what the agent can do. **My project in simple words:**

A chemical kinetic modeling engineer can run experiments on the computer. In my research, I use Reaction Mechanism Generator (RMG) to run my experiments for me. RMG is an automatic chemical reaction mechanism generator: using a general understanding of how molecules react, it builds kinetic models made of the simplest chemical reaction steps. RMG runs on my computer, starting from an input file, which is a Python script that gives RMG the data it needs to build the mechanism and create the model. The model contains all the reactions and the species (the molecules) that RMG constructed. RMG runs on code that tells it what to do next and where to extract data from.

In my research, the code for the model I am trying to generate, polymer decomposition, is not yet solved, and no program can create this mechanism for now. This is why an agent could contribute to the development of, and the work on, the thousands of lines of code working behind the scenes in RMG. The agent will help the user create the desired reaction families or species, based on the user's science-based knowledge.
